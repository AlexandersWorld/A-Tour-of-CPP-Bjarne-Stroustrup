# A Tour of C++

This repository contains my studies, exercises, notes, and experiments while working through **A Tour of C++** by **Bjarne Stroustrup**, the creator of C++.

The goal of this repository is to build a strong understanding of modern C++ fundamentals and gradually develop the knowledge required to write professional, low-level C++ code.

## 📚 Book

**A Tour of C++**
Bjarne Stroustrup

[Amazon](https://www.amazon.com.br/Tour-C-Bjarne-Stroustrup/dp/0136816487)

## 🎯 Goals

Through this study, I aim to develop a solid understanding of:

- Modern C++ syntax and language features
- Types and variables
- Pointers and references
- Const correctness
- Functions
- Classes and structs
- Object-oriented programming
- Resource management
- RAII
- Templates
- Generic programming
- Standard Library
- Containers and algorithms
- Error handling
- Concurrency
- Performance and low-level programming

The long-term objective is to use these fundamentals in **professional AAA game development**, particularly with **Unreal Engine and C++**.

## 🧠 Study Approach

This repository is not intended to simply contain copied examples from the book.

The focus is on:

1. Understanding the underlying concepts.
2. Writing the code myself.
3. Experimenting with the language.
4. Breaking things intentionally to understand why they fail.
5. Solving exercises without immediately looking at the answer.
6. Connecting C++ concepts to real-world software and game development.

> **The goal is understanding, not memorization.**
